# Katerina-Homika---Qualification-work

This project is website, which was created for integrate inventory system. The system checks and updates available product stock in real time.
The main project functions are:
- add product to the cart;
- complete the order;
- check product availability before complete the order;
- update product stock after order and show correct information on the website;
- the system will not allow to add more items to the cart that are available in stock;
- automatically diactivate 'Add to cart' button if the product is out-of-stock

## Technologies
- Java
- Spring Boot
- MySQL database
- HTML
- developed in IntelliJ IDEA

## How to run
1. Open the project in IntelliJ IDEA
2. Run the Main class
3. Open the website: http://localhost:8082/
